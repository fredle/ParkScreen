Release notes

What changed in each version of ParkScreen for Windows. The app updates itself, so you get these automatically.

Download the latest

Display driver 0.1.15 Latest

5 October 2026
  • The display driver is now signed with a real publisher certificate (FBL Consulting Ltd) instead of a test certificate. Windows no longer needs test-signing mode and Secure Boot can stay on.
  • Windows asks once, “Would you like to install this device software?”, because the driver is not signed by Microsoft. Choose Install. The driver comes through the existing Install or Update display driver tray item; no app update is needed.
  • Still early: tested on one Windows 11 PC so far.

0.1.11

4 October 2026
  • Tray menu: Reset connection now drops every stream, signs in to the server again, and leaves streaming paused, so the car does not jump straight back. Untick Pause streaming to let cars connect again.
  • Car page: a Disconnect button (top right while streaming) closes the connection from the car and stays disconnected until you tap Reconnect.

0.1.10

4 October 2026
  • Display driver install from the tray (for Extend mode): Install display driver (needs admin)… downloads the driver, checks it, and installs it with a single administrator prompt. Nothing is installed without you choosing it.
  • When a newer driver exists the menu offers Update display driver…. It checks after start and twice a day once a driver is installed.
  • The driver is an early, test-signed build: Windows must be in test-signing mode to load it, and the installer tells you if it is not. It has not yet been tested on a wide range of PCs.
  • Also from a terminal: parkscreen-host driver check and parkscreen-host driver install.

0.1.9

4 October 2026
  • New app icon: a monitor with a car on it, in Explorer, the taskbar, the installer and the tray.
  • Tray menu: Reset connection drops every stream and signs in to the server again; cars reconnect by themselves.
  • Tray menu: Pause streaming disconnects every car and refuses new connections until you untick it.
  • Car page: when the connection drops it now retries three times by itself, and shows Reconnect and Reset pairing buttons so it is never stuck. Short network blips no longer show an error.

0.1.8

4 October 2026
  • Tray menu: choose Duplicate (the car shows your main screen) or Extend. Extend stays greyed out until the ParkScreen display driver is installed; the driver is not released yet.
  • Tray menu: Check for updates.
  • Your display choice is remembered between runs.
  • Service: the server can hand out relay (TURN) credentials for cars and PCs on strict networks. It is off until it is configured.

0.1.7

4 October 2026
  • Touch from the car. Taps and drags on the car's screen become real multi-touch input on your PC, and scrolling uses the mouse wheel.
  • Touch is opt-in: start ParkScreen with --with-input. There is no tray switch yet.

0.1.6

4 October 2026
  • System tray menu: connection status, Pair a car… (shows the code), open the website, Start with Windows, Quit.
  • No console window, only one copy runs at a time, and nothing needs administrator rights.
  • Command-line options (--pair, list, --help) still work from a terminal; --no-tray runs without the tray.

0.1.5

4 October 2026
  • New website: an introduction with a download button at parkscreen.web.app. The car page moved to /car/; cars that are already paired go straight to it.
  • The app itself is unchanged from 0.1.4.

0.1.4

3 October 2026
  • Release packaging: every version keeps a permanent installer copy, as the Microsoft Store requires. The app is unchanged from 0.1.3.

0.1.3

3 October 2026
  • Automatic updates. The app checks for a newer version a minute after it starts and every four hours, downloads it in the background, and restarts into it once no car is streaming.

0.1.2

3 October 2026
  • Fixed the installer pausing for about 30 seconds and logging an error while it set the app up.
  • Fixed pairing: asking for a code before the app had signed in to the server meant no code was ever shown.

0.1.1

3 October 2026
  • First release that connects to the ParkScreen service out of the box. Signed installer.
  • Streams one monitor to the car's browser over WebRTC (H.264), with the mouse pointer drawn in, hardware encoding where available, and adaptive bitrate.

0.1.0 Superseded

3 October 2026
  • First test build. It had no service address built in, so it could not pair. Use a later version.
